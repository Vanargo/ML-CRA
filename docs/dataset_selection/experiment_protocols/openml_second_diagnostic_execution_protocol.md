# Протокол запуска второго диагностического контура OpenML-кандидатов

## 1. Что запускается

Запускается дополненная тетрадь `notebooks/04_dataset_smoke_experiments.ipynb` после добавления ячеек REPORT_29.

## 2. Что запрещено делать перед запуском

Нельзя менять `dataset_candidate_registry.csv`, менять статусы кандидатов, удалять строки из протоколов, подбирать гиперпараметры или интерпретировать контур с идентификаторами как финальное качество модели.

## 3. Ожидаемые выходы

Ожидаются три файла:

1. `data_registry/openml_second_diagnostic_scores.csv`;
2. `data_registry/openml_second_diagnostic_summary.csv`;
3. `data_registry/openml_second_diagnostic_warnings.csv`.

## 4. Что прислать после запуска

После выполнения нужно прислать три выходных CSV-файла. Если выполнение остановится, нужно прислать номер ячейки и полный текст ошибки.
