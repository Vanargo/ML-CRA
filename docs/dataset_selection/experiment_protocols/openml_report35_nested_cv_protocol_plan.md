# План `REPORT_35`: вложенная проверка MiniBooNE

## Назначение

`REPORT_35` должен подготовить, но еще не запускать, вложенный протокол для `openml_miniboone_41150`.

Задача вложенного протокола — отделить выбор параметров модели от внешней оценки качества.

## Зафиксированные решения

1. Кандидат: `openml_miniboone_41150`.
2. Признаки: `ParticleID_0` ... `ParticleID_49`.
3. Целевая переменная: `signal`.
4. Основная модель для настройки: `hist_gradient_boosting`.
5. Контрольные модели: `logistic_regression`, `dummy_prior`.
6. Основной критерий выбора параметров: `average_precision` / PR-AUC.
7. Отчетные метрики: ROC-AUC, PR-AUC, F1, balanced accuracy, log loss, Brier score.
8. Статус будущих результатов: `nested_research_draft` до отдельного отчета проверки.
