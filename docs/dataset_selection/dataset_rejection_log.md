# Журнал отклонений наборов данных

Основной машинно-читаемый файл:

```text
data_registry/dataset_rejection_log.csv
```

Этот markdown-файл нужен для пояснений к журналу отклонений.

## Категории отклонения

| Категория | Смысл |
|---|---|
| unclear_license | неясная лицензия |
| no_target | нет целевой переменной |
| weak_documentation | слабая документация |
| too_small | слишком маленький набор данных |
| too_large | слишком большой набор данных |
| too_overused | слишком заезженный набор данных |
| synthetic_or_toy | синтетический или игрушечный набор данных |
| compute_too_heavy | слишком высокая вычислительная нагрузка |
| legal_or_ethical_risk | правовой или этический риск |
| excessive_preprocessing | чрезмерная предобработка |
| unsuitable_task_type | неподходящий тип задачи |
| duplicated_candidate | повтор кандидата |
| other | другое |

## Правило

Каждый серьезно рассмотренный, но отклоненный набор данных должен получить запись в журнале отклонений.
