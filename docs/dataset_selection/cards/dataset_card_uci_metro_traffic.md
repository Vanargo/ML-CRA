# Карточка набора данных: uci_metro_traffic

## 1. Идентификация

- Внутренний идентификатор кандидата: `uci_metro_traffic`
- Название набора данных: Metro Interstate Traffic Volume
- Источник: UCI Machine Learning Repository
- Стабильная ссылка: `https://archive.ics.uci.edu/ml/datasets/Metro+Interstate+Traffic+Volume`
- Текущий статус: короткий список, не принят в первую минимальную версию

## 2. Тип задачи

- Тип задачи: регрессия
- Целевая переменная: `traffic_volume`
- Смысл целевой переменной: часовой объем транспортного потока
- Количество наблюдений по UCI: 48 204
- Количество признаков по UCI: 8
- Временная структура: часовые записи за 2012–2018 годы
- Пропуски по UCI: нет

## 3. Значимость для ML-CRA

Набор полезен как регрессионная задача с временной структурой, погодными признаками и календарными признаками.

Потенциальные утверждения:

1. «Модель A лучше модели B при регрессии транспортного потока».
2. «Случайное разбиение завышает надежность утверждения по сравнению с временным».
3. «Метрики регрессии дают согласованный или конфликтующий вывод».

## 4. Обоснование решения

UCI описывает набор как часовой транспортный поток западного направления I-94 между Minneapolis и St Paul, с погодными и праздничными признаками за 2012–2018 годы. Задача указана как регрессия, 48 204 наблюдения, 8 признаков, пропусков нет.

## 5. Риски

- Может сместить проект в прогнозирование временных рядов.
- Нужно не допустить утечки через признаки даты при некорректном разбиении.
- Нужно ограничить роль этого набора как одного из регрессионных кандидатов, а не отдельной большой темы.

## 6. Решение

- Статус: короткий список
- Решение: оставить
- Уровень уверенности: высокий
