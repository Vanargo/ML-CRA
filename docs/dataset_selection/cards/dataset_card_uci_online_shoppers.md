# Карточка набора данных: uci_online_shoppers

## 1. Идентификация

- Внутренний идентификатор кандидата: `uci_online_shoppers`
- Название набора данных: Online Shoppers Purchasing Intention
- Источник: UCI Machine Learning Repository
- Стабильная ссылка: `https://archive.ics.uci.edu/ml/datasets/Online+Shoppers+Purchasing+Intention+Dataset`
- Текущий статус: короткий список, не принят в первую минимальную версию

## 2. Тип задачи

- Тип задачи: бинарная классификация
- Целевая переменная: `Revenue`
- Смысл целевой переменной: завершилась ли сессия покупкой
- Количество признаков по UCI: 10 числовых и 8 категориальных
- Единица наблюдения: сессия пользователя на сайте

## 3. Значимость для ML-CRA

Набор полезен как реальная табличная бинарная классификация со смешанными признаками и дисбалансом классов.

Потенциальные утверждения:

1. «Модель A лучше модели B при дисбалансе классов».
2. «Победа модели сохраняется при разных метриках».
3. «Обработка категориальных признаков влияет на надежность утверждения».

## 4. Обоснование решения

UCI указывает, что набор содержит 10 числовых и 8 категориальных признаков, а `Revenue` используется как метка класса. Это делает набор релевантным для проверки конфликта метрик и устойчивости утверждений в бинарной классификации.

## 5. Риски

- Набор достаточно известен.
- Нужно проверить фактический баланс классов локально.
- Нужно проверить, нет ли признаков, которые создают риск нереалистичной постановки.

## 6. Решение

- Статус: короткий список
- Решение: оставить
- Уровень уверенности: высокий
- Условие дальнейшего использования: выполнить локальную загрузку и первичный просмотр данных
