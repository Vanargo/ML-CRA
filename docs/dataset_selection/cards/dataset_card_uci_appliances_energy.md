# Карточка набора данных: uci_appliances_energy

## 1. Идентификация

- Внутренний идентификатор кандидата: `uci_appliances_energy`
- Название набора данных: Appliances Energy Prediction
- Источник: UCI Machine Learning Repository
- Стабильная ссылка: `https://archive.ics.uci.edu/ml/datasets/Appliances+energy+prediction`
- Текущий статус: короткий список, не принят в первую минимальную версию

## 2. Тип задачи

- Тип задачи: регрессия
- Целевая переменная: `Appliances`
- Смысл целевой переменной: энергопотребление бытовых приборов
- Временная структура: шаг 10 минут примерно за 4.5 месяца
- Единица наблюдения: десятиминутный интервал наблюдений

## 3. Значимость для ML-CRA

Набор полезен как регрессионная табличная задача с временной структурой.

Потенциальные утверждения:

1. «Модель A лучше модели B в регрессии».
2. «Победитель меняется при случайном и временном разбиении».
3. «Выигрыш сложной модели оправдан с учетом вычислительной стоимости».

## 4. Обоснование решения

UCI указывает, что данные имеют шаг 10 минут примерно за 4.5 месяца, а измерения включают температуру, влажность и энергопотребление. Это делает набор данных релевантным для проверки временного разбиения в регрессионной задаче.

## 5. Риски

- Есть риск смещения проекта в прогнозирование временных рядов.
- Для ML-CRA набор должен использоваться как табличная регрессия с временным разбиением, а не как отдельная задача временного ряда.
- Нужно проверить признаки на возможную утечку через время или производные переменные.

## 6. Решение

- Статус: короткий список
- Решение: оставить
- Уровень уверенности: высокий
- Условие дальнейшего использования: выполнить локальную загрузку и подтвердить структуру признаков
