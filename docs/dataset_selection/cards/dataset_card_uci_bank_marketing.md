# Карточка набора данных: uci_bank_marketing

## 1. Идентификация

- Внутренний идентификатор кандидата: `uci_bank_marketing`
- Название набора данных: Bank Marketing
- Источник: UCI Machine Learning Repository
- Стабильная ссылка: `https://archive.ics.uci.edu/dataset/222/bank+marketing`
- Текущий статус: условный кандидат, не принят в первую минимальную версию

## 2. Тип задачи

- Тип задачи: бинарная классификация
- Целевая переменная: `y`
- Смысл целевой переменной: подписался ли клиент на срочный депозит
- Предметная область: прямой маркетинг португальского банка

## 3. Значимость для ML-CRA

Набор полезен как пример, где одно поле может сделать постановку нереалистичной.

Потенциальные утверждения:

1. «Модель A лучше модели B при наличии признака `duration`».
2. «Преимущество модели сохраняется после исключения `duration`».
3. «Утверждение о превосходстве модели хрупко к реалистичности признакового пространства».

## 4. Обоснование решения

UCI прямо предупреждает, что `duration` сильно влияет на целевую переменную, но неизвестен до звонка; после звонка целевой результат уже фактически известен. Поэтому этот признак можно использовать только для сравнительных тестов, но его нужно исключать, если цель — реалистичная предсказательная модель.

Для ML-CRA это методологически полезный кандидат: он позволяет показать, что утверждение о превосходстве модели может быть искусственно усилено нереалистичным признаком.

## 5. Риски

- Набор сильно известен и заезжен.
- Признак `duration` создает риск нереалистичной постановки.
- Нельзя использовать как основной доказательный набор.
- Нужны две версии постановки: с `duration` и без `duration`.

## 6. Решение

- Статус: условно в коротком списке
- Решение: оставить условно
- Уровень уверенности: средний
- Условие дальнейшего использования: до обучения моделей зафиксировать протокол исключения или отдельного анализа `duration`
