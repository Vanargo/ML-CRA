# Карточка набора данных: uci_cdc_diabetes

## 1. Идентификация

- Внутренний идентификатор кандидата: `uci_cdc_diabetes`
- Название набора данных: CDC Diabetes Health Indicators
- Источник: UCI Machine Learning Repository
- Стабильная ссылка: `https://archive.ics.uci.edu/dataset/891/cdc+diabetes+health+indicators`
- Текущий статус: условный кандидат, не принят в первую минимальную версию

## 2. Тип задачи

- Тип задачи: классификация
- Целевая переменная: диабет / предиабет / здоровый статус
- Количество наблюдений по UCI: 253 680
- Количество признаков по UCI: 21
- Предметная область: здоровье и медицина

## 3. Значимость для ML-CRA

Набор полезен как крупная медицинская табличная классификация с потенциальным дисбалансом классов.

Потенциальные утверждения:

1. «Модель A лучше модели B на крупной медицинской табличной задаче».
2. «Вывод устойчив при разных метриках».
3. «Метрики, чувствительные к дисбалансу, меняют интерпретацию победителя».

## 4. Обоснование решения

UCI описывает набор как данные медицинской статистики, образа жизни и диагноза диабета; указаны 253 680 наблюдений и 21 признак. Это делает набор технически сильным кандидатом для проверки устойчивости утверждений на крупной табличной классификации.

## 5. Риски

- Медицинская область требует осторожности.
- Нельзя формулировать медицинские рекомендации.
- Возможна заезженность из-за популярности на Kaggle.
- Нужно явно указать, что ML-CRA проверяет методологию утверждений, а не строит медицинский диагностический инструмент.

## 6. Решение

- Статус: условно в коротком списке
- Решение: оставить условно
- Уровень уверенности: средний
- Условие дальнейшего использования: добавить этическое ограничение и проверить фактический баланс классов
