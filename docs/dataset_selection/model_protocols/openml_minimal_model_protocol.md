# Протокол первичного минимального набора моделей OpenML

## 1. Статус

Этот протокол определяет минимальный набор моделей для первого диагностического контура OpenML.

Модели пока не обучаются. Протокол только фиксирует, какие модели допустимы в первой версии и почему.

## 2. Основной принцип

Первый контур должен быть достаточно малым, чтобы не перегрузить проект, но достаточно разнообразным, чтобы проверять утверждения о превосходстве моделей.

Поэтому первый контур ограничивается scikit-learn-моделями.

## 3. Модели первого контура

### 3.1 DummyClassifier

Роль: модель-заглушка.

Назначение: проверить, что настоящие модели превосходят тривиальный прогноз, игнорирующий признаки.

### 3.2 LogisticRegression

Роль: простая линейная базовая модель.

Назначение: дать понятную и относительно дешевую модель для сравнения со сложными нелинейными моделями.

### 3.3 HistGradientBoostingClassifier

Роль: основная нелинейная модель первого контура.

Назначение: проверить, дает ли табличная нелинейная модель устойчивое преимущество над простой линейной моделью.

### 3.4 RandomForestClassifier

Роль: условная дополнительная древовидная модель.

Назначение: независимая проверка против бустинга, но только если вычислительная нагрузка остается управляемой.

## 4. Отложенные модели

### 4.1 CatBoostClassifier

Отложен, потому что добавляет внешнюю зависимость и может слишком рано сместить проект в сравнение библиотек. Его имеет смысл вернуть после стабилизации scikit-learn-контура.

### 4.2 LightGBMClassifier

Отложен по той же причине: сильная модель, но внешняя зависимость и дополнительная сложность.

## 5. Dataset-specific решения

### 5.1 electricity

Разрешены:

1. DummyClassifier;
2. LogisticRegression;
3. HistGradientBoostingClassifier;
4. RandomForestClassifier условно.

### 5.2 MiniBooNE

Разрешены:

1. DummyClassifier;
2. LogisticRegression;
3. HistGradientBoostingClassifier;
4. RandomForestClassifier условно.

### 5.3 Click_prediction_small

Разрешены:

1. DummyClassifier;
2. LogisticRegression только с безопасной политикой идентификаторов;
3. HistGradientBoostingClassifier условно, только с безопасной политикой идентификаторов.

CatBoost и LightGBM отложены.

## 6. Запрещено

До утверждения этого протокола нельзя:

1. обучать модели;
2. добавлять внешние библиотеки;
3. сравнивать CatBoost, LightGBM и XGBoost;
4. использовать идентификаторы в Click_prediction_small без протокола;
5. подгонять предобработку на полном наборе данных до разбиения.
