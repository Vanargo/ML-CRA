## Работаем по следующему плану

Агент должен:

1. проверить исходное состояние;
2. прочитать обязательные источники полностью;
3. зафиксировать существенные неопределённости;
4. сформировать минимальный планируемый набор изменений или план анализа;
5. выполнить профильную работу в разрешённых границах;
6. провести применимые проверки;
7. исправить обнаруженные дефекты без выхода за границы;
8. выполнить самопроверку;
9. сопоставить планируемый набор и журнал фактических изменений;
10. сформировать доказательную запись или отчёт;
11. создать ZIP только при выполнении установленных условий;
12. выдать технический вердикт и остановиться.

## Протокол завершения

Агент может присвоить только:

```text
TECHNICAL_STATUS: PASS | FAIL | BLOCKED
READINESS: READY_FOR_JOHN_ACCEPTANCE | NOT_READY
```

Только John может присвоить:

```text
ACCEPTED_BY_JOHN
TASK_CLOSED
NEXT_BLOCK_AUTHORIZED
```

Автоматический переход к следующей задаче запрещён.
