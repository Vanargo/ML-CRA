# Профиль `ANALYSIS_ONLY` — «только анализ»

Применять вместе с `task_core_v01.md`, когда результатом является анализ,
диагностика, обзор, план или рекомендация без изменения состояния проекта.

## Дополнительные обязательные поля

```text
project_changes: prohibited
external_side_effects: prohibited
checkpoint_required: false
```

Определить:

- вопросы анализа;
- анализируемые файлы и контрольную точку;
- критерии достаточности охвата;
- требуемую форму отчёта;
- разрешено ли предлагать следующую задачу.

## Профильные правила

1. Не изменять проектные файлы, метаданные или архив.
2. Не запускать команды с изменяющим побочным эффектом.
3. Разделять локальные факты, наблюдения, внешние основания, выводы и
   неопределённости.
4. Не превращать рекомендацию в разрешённую изменяющую задачу.
5. Если анализ выявил дефект, описать его и достаточную следующую постановку,
   но не исправлять без отдельной задачи `CHANGE`.

## Профильные доказательства

- перечень полностью прочитанных источников;
- охват анализа и явные исключения;
- ответы на поставленные вопросы;
- неопределённости и ограничения;
- рекомендуемая следующая задача, только если это разрешено.
