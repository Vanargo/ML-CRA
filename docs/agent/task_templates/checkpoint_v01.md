# Профиль `CHECKPOINT` — «контрольная точка»

Применять вместе с `task_core_v01.md` для проверки и упаковки
воспроизводимого состояния ML-CRA.

## Дополнительные обязательные поля

Определить:

- источник контрольной точки;
- ожидаемое корневое имя каталога;
- обязательный набор файлов;
- исключения;
- проверки целостности и воспроизводимости;
- правила именования ZIP;
- место записи SHA-256;
- допускаются ли исправления или профиль является только упаковочным.

## Профильные правила

1. Не считать упаковку разрешением изменить проектное содержание.
2. Проверить обязательные файлы, структуру, документацию и применимые
   регрессии до архивации.
3. Исключить виртуальные среды, `__pycache__`, `*.pyc`, временные файлы,
   notebook checkpoints и локальные аналитические материалы.
4. Проверить отсутствие лишнего внешнего уровня каталога и неоднозначных
   дубликатов.
5. Сформировать ZIP детерминированным или явно документированным способом.
6. Вычислить SHA-256 итогового ZIP и проверить читаемость архива.
7. Не объявлять контрольную точку принятой от имени John.

## Профильные доказательства

- исходный и итоговый инвентарь;
- применённые исключения;
- результаты обязательных проверок;
- имя ZIP, размер и SHA-256;
- результат проверки целостности архива;
- известные ограничения воспроизводимости;
- статус готовности к принятию John.
